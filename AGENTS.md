# Itinea website

This repository contains the public-facing website for Itinea Viajes. Keep its brand and product decisions local to this project; do not import rules or architecture from unrelated repositories.

## Brand facts

- The public Instagram profile identifies the business as “Itinea Viajes”, uses the line “Diseñamos Experiencias”, and displays “Legajo N.º 21064”.
- The visible identity is turquoise and white, with an airplane mark and destination photography.
- Treat Instagram as a source for public brand facts and visual direction. Do not invent prices, contact details, destinations on sale, customer reviews, locations, or legal claims.
- The current scope is a static landing page. Add a backend, store, analytics, booking flow, CMS, or other service only when a future request establishes a need.
- The Instagram profile is the only verified contact route in this brief.

## Project guidance

- For a new or substantial website build, read `.agents/skills/itinea-web-studio/SKILL.md`.
- For a UI/accessibility review, read `.agents/skills/web-design-guidelines/SKILL.md`; its retrieval step is adapted for Codex.
- For customer-facing copy edits, use `.agents/skills/humanizer/SKILL.md` while preserving supported facts.
- Use `.agents/skills/cro-optimization/SKILL.md` only after launch when real traffic, outcome data, and an experiment path exist.
- Use `.agents/skills/scroll-craft/SKILL.md` only when a project brief calls for substantial scroll-driven storytelling; ordinary transitions do not need its runtime.
- Keep every visible link and control functional. Respect reduced motion, keyboard use, readable contrast, and small screens.
- Prefer a small, static implementation for this landing page. Avoid adding dependencies or external services without a concrete requirement.
