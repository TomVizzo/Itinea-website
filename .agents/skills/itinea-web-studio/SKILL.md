# Itinea Web Studio

Create a distinctive, coherent website that fits the brief and works for real visitors. Treat this repository's `AGENTS.md` as the source of project-specific facts and boundaries.

## Workflow

1. Read the existing page, assets, and project instructions before choosing an implementation.
2. Identify the audience, primary action, verified content, and the smallest architecture that supports the requested experience. Do not add a backend, store, form endpoint, analytics, or integration without a stated need.
3. Establish a small visual system: type hierarchy, spacing, color roles, image treatment, and interaction states. Make the page recognizable through its composition and real brand cues, not decorative effects alone.
4. Write natural, specific Spanish copy. Keep claims within supplied evidence. Use the Humanizer skill when editing prose, not as a reason to invent a brand voice or facts.
5. Build mobile-first semantic HTML and responsive layouts. Ensure navigation, calls to action, and other visible controls have real outcomes.
6. Add motion only when it clarifies the experience. Prefer short opacity/transform transitions, support `prefers-reduced-motion`, and keep all content available without animation.
7. Include page-specific title and description, social metadata where an absolute production URL is known, and structured data only for facts that are actually available.
8. Review the rendered page at narrow and wide viewports. Inspect keyboard focus, heading order, link destinations, image loading, console errors, and reduced-motion behavior. Report what was and was not checked.

## Itinea guardrails

- Use the source facts and brand cues documented in `AGENTS.md`.
- Do not publish a generated or stock visual as documentary proof of an Itinea trip. Label concept imagery accurately and replace it with approved brand photography before production publication.
- Link contact actions to the verified Instagram profile until Itinea supplies another destination.
- Keep the site independent from the WhatsApp AI Agent V2 project's stack and instructions.
